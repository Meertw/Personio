# 15 – Personio Assistant (AI)

> **Waarom belangrijk?** De **Personio Assistant** kan het **personeelshandboek** gebruiken, bijv. vanuit **SharePoint**. Zo kunnen HR en medewerkers informatie uit het handboek opvragen in Personio, in plaats van dat HR steeds dezelfde vragen beantwoordt.

## Controlepunten

| # | Controlepunt | Score (0-3) | Bevinding | Advies | Prio |
|---|--------------|-------------|-----------|--------|------|
| 15.1 | De Personio Assistant is beschikbaar en geactiveerd | | | | |
| 15.2 | Het personeelshandboek (bijv. vanuit SharePoint) is gekoppeld als bron voor de Assistant | | | | |
| 15.3 | Het handboek is actueel en er is een eigenaar die het bijhoudt (de Assistant is zo goed als de bron) | | | | |
| 15.4 | Er is bepaald welke documenten wél en niet als bron dienen (geen vertrouwelijke of verouderde documenten) | | | | |
| 15.5 | Het handboek is per entiteit / land waar nodig gesplitst, zodat medewerkers het antwoord krijgen dat voor hen geldt | | | | |
| 15.6 | HR en medewerkers weten dat ze de Assistant kunnen gebruiken (communicatie / korte instructie) | | | | |
| 15.7 | Antwoorden worden steekproefsgewijs gecontroleerd op juistheid | | | | |

## Datacheck

- [ ] Waar staat het handboek nu (SharePoint, intranet, PDF) en wanneer is het voor het laatst bijgewerkt?
- [ ] Top 10 vragen die HR het vaakst krijgt: staan de antwoorden in het handboek?
- [ ] Testvragen stellen aan de Assistant en antwoorden vergelijken met het handboek

## Veelvoorkomende hiaten

- Het handboek staat verspreid over meerdere plekken, of is verouderd
- HR beantwoordt dezelfde vragen steeds handmatig
- Eén handboek voor alle entiteiten, terwijl de regels verschillen

## Praktijktips

- De **Assistant** kan het **personeelshandboek uit SharePoint** gebruiken. Haal de informatie daaruit binnen, zodat **HR** (en medewerkers) het daar kunnen **opvragen**.

## Opleverpunten voor de klant

- Advies voor het koppelen van het handboek als bron
- Lijst met veelgestelde HR-vragen en of het handboek ze beantwoordt
