# Personio Quickscan

Quickscan-template om bij klanten te beoordelen of hun Personio-omgeving compleet en goed ingericht is, welke workflows geoptimaliseerd kunnen worden en waar hiaten zitten.

## Hoe gebruik je de quickscan

1. Start met de **intake** (`quickscan/00-intake.md`) om de context van de klant vast te leggen.
2. Loop de modules **in volgorde** door. De volgorde volgt de logica van inrichten: wat bovenaan staat is fundament voor wat eronder komt.
3. Geef per controlepunt een score volgens `quickscan/scoring.md` en noteer bevindingen + advies.
4. Vat samen in het adviesrapport: hiaten, quick wins en vervolgstappen.
